# Arnoya AI Website

Static RTL Persian landing page for GitHub Pages.

## Files
- `index.html` - main page
- `style.css` - visual system and responsive layout
- `script.js` - small navigation enhancement
- `assets/arnoya-mark.svg` - favicon / brand mark
- `.nojekyll` - disables Jekyll processing for predictable static hosting

## GitHub Pages
Upload all files to the repository root and enable Pages from `main` / `/ (root)`.
